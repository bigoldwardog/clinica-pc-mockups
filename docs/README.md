# Mockups de la Clínica del PC

Descarga [mockups.html](mockups.html) y ábrelo en el navegador. El prototipo usa datos ficticios. Los formularios simulan acciones en pantalla y las pantallas muestran ejemplos independientes.

| Paso de la guía | Pantalla | Resultado esperado para validar con el cliente |
| --- | --- | --- |
| 1 | Inscripción por QR | El propietario puede identificar dos dispositivos en una inscripción y recibe confirmación. |
| 2 | Recepción | Tras validar el RUT, recepción selecciona el equipo correcto y registra serie, diagnóstico y servicio. |
| 3 | Verificación inicial | El técnico registra el funcionamiento y las fallas preexistentes antes de intervenir. |
| 4 | Checklist | El servicio determina qué tareas se muestran. El mockup ilustra mantención física. |
| 5 | Observaciones | La observación queda asociada a la orden del equipo seleccionado. |
| 6 | Verificación posterior | El técnico compara los resultados con el estado inicial y documenta cualquier diferencia. |
| 7 | Contacto y entrega | Se registra el intento de contacto y, si hay respuesta, el acuerdo de retiro. |
| 8 | Prueba conjunta | El técnico registra el resultado de la prueba realizada con el propietario. |
| 9 | Cierre | Se confirma la entrega y se registra un estado final en la orden. |
